# fireflyDSA
This repository is meant for application based code snippets.
Most of the DSA here will be applied to some form of real world example (e.g: Listing open ports, listing files and directories or ongoing processes on the system).
Rules are simple: 
1. Find a real world source of data.
2. Apply DSA knowledge and check how it can be stored.
3. Develop its implementation as a code snippet.
4. Upcoming projects: Color Conversion RGB to CMYK, Capturing metadata of the connected devices (I/O information), Capturing PC specsheet and uploading it to designated email address.
